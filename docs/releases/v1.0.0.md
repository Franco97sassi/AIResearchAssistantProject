# AI Research Assistant v1.0.0

First stable portfolio release of the full-stack PDF research assistant.

## Highlights

- Traceable RAG answers with file and page citations.
- LangGraph research workflow and an MCP server over the same knowledge base.
- Tenant-scoped retrieval and authenticated tenant data erasure.
- Idempotent PDF jobs with bounded Redis/RQ retries.
- Reproducible retrieval benchmark and CI quality gate.
- Prometheus/Grafana monitoring plus opt-in OpenTelemetry OTLP traces.
- Immutable SHA deployments, health checks, backup/restore, and automatic rollback.

## Upgrade and operations notes

- Configure `JOB_MAX_RETRIES` and `JOB_RETRY_INTERVAL_SECONDS` for the worker workload.
- Set `OTEL_ENABLED=true` and `OTEL_EXPORTER_OTLP_ENDPOINT` to export traces.
- Clients should send an `Idempotency-Key` header when creating asynchronous upload jobs.
- Tenant erasure returns HTTP 409 while that tenant has an active indexing job; retry after it
  finishes so erased vectors cannot be recreated by an in-flight worker.

## Known limitations

The versioned retrieval corpus is synthetic, local persistence is intended for a single replica,
and streaming is not yet native provider streaming. Consult `README.md` before production use.
